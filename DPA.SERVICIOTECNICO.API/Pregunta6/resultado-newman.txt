□ OrdenReparacion (controlador con repositorio)
└ Listar órdenes de reparación
  GET http://localhost:5181/api/OrdenReparacion [200 OK, 678B, 3ms]
  √  Código de estado 200 OK
  √  La respuesta es JSON
  √  Devuelve un arreglo con las órdenes de reparación
  √  Cada orden trae los campos del contrato
  √  El equipo y el tipo de reparación vienen como texto
  √  Cada estado es uno de los permitidos
  √  La orden inicial 1 muestra su equipo y su tipo de reparación

└ Crear orden de reparación
  POST http://localhost:5181/api/OrdenReparacion [201 Created, 443B, 7ms]
  √  Código de estado 201 Created
  √  La orden creada trae su id y los datos enviados
  √  La fecha de ingreso es la de hoy (no se envió en el cuerpo)
  √  La cabecera Location apunta a la nueva orden

└ Obtener orden de reparación por id
  GET http://localhost:5181/api/OrdenReparacion/6 [200 OK, 383B, 3ms]
  √  Código de estado 200 OK
  √  Devuelve la orden recién creada
  √  Muestra el equipo y el tipo de reparación por su nombre

└ Actualizar orden de reparación
  PUT http://localhost:5181/api/OrdenReparacion/6 [200 OK, 412B, 7ms]
  √  Código de estado 200 OK
  √  Devuelve la orden con los cambios

└ Obtener orden de reparación actualizada
  GET http://localhost:5181/api/OrdenReparacion/6 [200 OK, 412B, 3ms]
  √  Código de estado 200 OK
  √  La descripción, el costo y el estado muestran el cambio
  √  Se mantienen el equipo y el tipo de reparación
  √  La fecha de ingreso sigue siendo la de hoy (el PUT no la envía)

└ Eliminar orden de reparación
  DELETE http://localhost:5181/api/OrdenReparacion/6 [204 No Content, 81B, 4ms]
  √  Código de estado 204 No Content
  √  La respuesta no trae cuerpo

└ Obtener orden de reparación eliminada (404)
  GET http://localhost:5181/api/OrdenReparacion/6 [404 Not Found, 325B, 3ms]
  √  Código de estado 404 Not Found
  √  Ya no devuelve los datos de la orden eliminada

└ Crear orden con equipo inexistente (400)
